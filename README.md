# Tuition Payment Dashboard

A web application designed to streamline the student registration, profile management, and tuition fee payment process for a tutoring or tuition center.

---

## 🚀 Key Features

The application provides a comprehensive platform for both new and existing students, featuring:

### 1. Student Registration & Onboarding
* **Simple Registration Form:** A dedicated form for new students to register with all necessary details (Name, Contact, Class/Grade, Subjects, etc.).
* **Registration Confirmation:** Immediate feedback upon successful registration with an **email confirmation** containing their temporary login credentials (password).

### 2. Secure Student Login
* **Dedicated Login Page:** Students can securely log in using their email and the provided password.
* **Password Management:** Includes a "Forgot password?" link for account recovery.

### 3. Comprehensive Student Dashboard
* **Personalized Welcome:** Greets the student by name and displays their associated email.
* **Quick Access Modules:** Dedicated sections for **Notes**, **Profile Editing**, and **Logout**.
* **Tuition Fees Management:** A prominent module to **Pay Tuition Fees** online.
* **Announcements:** A bulletin board for important updates, reminders (e.g., fee due dates), and new study material announcements.
* **Payment History:** A dedicated section to track past payment records.

### 4. Profile Management
* **Edit Profile Interface:** Students can update their personal and parent/guardian information.
* **Profile Picture Upload:** Option to upload and update a profile photo.

---

## 💻 Technologies Used ✨

This project is built using a modern and effective tech stack:

---

### Frontend & UI/UX

* **HTML5 & CSS3:** For the core structure and styling.
* **JavaScript (ES6+):** For client-side interactivity and dynamic functionality.
* **Tailwind CSS:** A utility-first CSS framework used for rapid and responsive UI development.
* **Flowbite:** An open-source component library built on top of Tailwind CSS, providing pre-designed UI elements.

### Backend & Database

* **PHP:** Used as the server-side scripting language for handling business logic, form submissions, and data processing.
* **MySQL:** The relational database management system used for storing and managing all student, payment, and application data.
